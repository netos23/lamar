# Scripts
___

Scripts collection for utility functions

Entrypoint scripts:
1. [make_examples.sh](make_examples.sh) - Script to generate example files for testing and demonstration purposes.
2. [cleanup_temp.sh](cleanup_temp.sh) - Script to clean up temporary files created
3. [docker_setup.sh](docker_setup.sh) - Script to set up Docker environment for the project.

Helper scripts:
1. [docker_lama.sh](docker_lama.sh) - Example script for run Docker containers for LaMa.
2. [build_examples.sh](build_examples.sh) - Script to build example files using specified parameters.
