# Scripts
___

Scripts collection for utility functions

Entrypoint scripts:
1. [make_examples.sh](make_examples.sh) - Script to generate regression fixtures (bytecode, inputs, outputs).
2. [cleanup_temp.sh](cleanup_temp.sh) - Script to clean up temporary files created
3. [docker_setup.sh](docker_setup.sh) - Script to set up Docker environment for the project.

Helper scripts:
1. [docker_lama.sh](docker_lama.sh) - Example script to run Docker containers for LaMa.
2. [build_examples.sh](build_examples.sh) - Script to build regression fixtures using specified parameters.
